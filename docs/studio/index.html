IDENTITÀ E CONTENUTO · ITALIANO
DESTINAZIONE E PUBBLICAZIONE

Seleziona un prodotto, una famiglia, una piattaforma o l'intero ecosistema. Più canali si uniscono: ogni prodotto riceve la comunicazione una volta sola.

I prodotti non ancora integrati sono visibili in anteprima, ma non riceveranno notifiche finché non avranno un client collegato.

Le campagne di collaudo non arrivano in produzione. Quelle di produzione compaiono anche in collaudo, così puoi verificarle prima o dopo la pubblicazione. Il feed di produzione rimane separato; nessun invio push automatico.

PRIORITÀ PROGRAMMATA

Alta: massimo una volta al giorno; media: una sola volta a chi non l'ha ancora vista; bassa: solo nello storico. Le date sono UTC.

TEMPLATE E FORMATI

Il template definisce formati, posizionamento e regole. Le azioni usano {{cta:primary}} (mai link HTML arbitrari).

In tutte le app lo storico mostra questo rettangolo; toccarlo apre la locandina integrale.

NOTIFICA NATIVA · TESTO ITALIANO

Il testo è distinto dal banner. Viene utilizzato soltanto quando l'utente ha autorizzato le notifiche e il servizio push è configurato.

PULSANTI DELLA LOcANDINA

Da 0 a 4 CTA native. Ogni pulsante viene creato dal publisher usando {{cta:id}}. I link esterni aggiungono source con l'ID dell'app che mostra la comunicazione.

CREATIVITÀ HTML / CSS

Solo contenuti statici: niente JavaScript, iframe, immagini esterne, font remoti o form. Usa {{headline}}, {{eyebrow}}, {{deck}}, {{footer}}.

Anteprima isolata

Il documento creativo viene mostrato in un iframe sandbox, senza script né navigazione.

L'editor è una prima versione HTML/CSS. La pubblicazione richiede PR, validazione nel repository privato e promozione esplicita.
